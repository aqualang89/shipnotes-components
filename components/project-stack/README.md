# Project Stack

Open `demo.html` and select a project. Three layered cards for a portfolio or featured-work section. The sample projects and destinations are placeholders.

Copy `project-stack.js`, load it with `<script src="project-stack.js" defer></script>`, then copy the `<project-stack>` block from the demo. Edit its three JSON entries: title, tag, description and href. Keep exactly three entries in this version.

Text is inserted as plain text; links allow HTTP(S) only. Keep descriptions short. Replace the CSS artwork inside the component if you need a different visual identity.

No dependencies. Styles are scoped with Shadow DOM; the parent controls width, up to the default 460px maximum. Tabs support Left/Right, Home and End. Only the active panel's link is focusable. Reduced motion disables transitions.
