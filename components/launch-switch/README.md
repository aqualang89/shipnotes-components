# Launch Switch

Open `demo.html`, then click the metal switch. It opens, spins up, lights the seam and closes again. Enter and Space work too. Reduced-motion preferences are supported.

This is a self-contained visual demo, not a deployment control or a reusable custom element. To adapt it, edit the HTML, styles and interaction code in the file. It does not deploy anything or call a server.

The file embeds GSAP 3.15.0. Its license notice is preserved; see [third-party terms](../../THIRD_PARTY.md). No internet connection is needed to play the demo.
