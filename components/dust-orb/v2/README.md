# Dust Orb v2

Run `python -m http.server 8080` in this folder, then open `http://localhost:8080/`.

Move the pointer toward the cloud, drag to rotate and tap to stir it. The buttons change the assistant state; Sound enables the optional Air + glass sound.

[Live demo](https://aqualang89.github.io/shipnotes-components/components/dust-orb/v2/)

[Setup, embedding and API](../README.md)

Built with JavaScript, Three.js and WebGL 2. No build step or API key. Connect your own voice and model through the component's API.
