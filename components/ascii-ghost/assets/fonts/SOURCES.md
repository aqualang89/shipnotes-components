# Demo font sources

These fonts are demo assets. The component itself does not fetch them.

- Archivo regular/bold: local shared font bank, upstream https://github.com/google/fonts/tree/main/ofl/archivo ; notice OFL-Archivo.txt.
- JetBrains Mono regular: local shared font bank, upstream https://github.com/JetBrains/JetBrainsMono ; notice OFL-JetBrains.txt.
- IBM Plex Mono regular: local shared font bank, upstream https://github.com/IBM/plex ; notice OFL-Plex.txt.
- Departure Mono 1.500: https://github.com/rektdeckard/departure-mono/blob/main/public/assets/DepartureMono-1.500.woff2 ; notice OFL-Departure.txt.

The exact Departure asset and all notices were fetched from the upstream repositories on 2026-10-28. Font files already available locally were copied without modification.
